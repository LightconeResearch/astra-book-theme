# astra book theme (published build)

This repository holds the **build artifacts** for the book flavor of
[astra-theme](https://github.com/LightconeResearch/astra-theme), a MyST web theme.
It is generated by CI — do not edit by hand. Open issues and PRs against the
source repo.

Use it in a MyST project:

```yaml
site:
  template: https://github.com/LightconeResearch/astra-book-theme.git
```

Published from `v0.0.15`.
